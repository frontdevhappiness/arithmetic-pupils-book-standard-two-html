Writing numbers in expanded form

A number can be written in expanded form using the total value of its digits.

Example 1

Write 462 in expanded form.

Answer:

462 = 400 + 60 + 2.

Example 2

Write 109 in expanded form.

Answer:

109 = 100 + 0 + 9.

Writing numbers in short form

A number in expanded form can be written in a short form as shown below.

Example 1

Write 200 + 70 + 3 in short form.

Answer:

200 + 70 + 3 = 273.

Example 2

Write 300 + 40 + 2 in short form.

Answer:

300 + 40 + 2 = 342.
